# Poly Haven terrain textures (CC0)

Source: Poly Haven (https://polyhaven.com), files https://dl.polyhaven.org. CC0 1.0, see LICENSE.txt (same licence text as art_sources/polyhaven_pbr).
Fetched with plain curl and the user agent `QuantumTeleportar-asset-fetch/1.0` by `godot/tools/materials/pack_terrain_textures.py` (1K JPG diffuse only). ambientCG (https://ambientcg.com) was tried first: its API answers, but the download host (acg-media / acg-download.struffelproductions.com) is refused by the session network policy (403 on CONNECT), so Poly Haven is used instead.
Raw downloads are not committed (`godot/assets_incoming/terrain_raw/`, git-ignored). Packed result: `godot/assets/textures/terrain_<layer>.webp` (1024 px, lossy WebP q82, VRAM compressed at import).

# Free Low Poly Vehicles Pack (selected vehicles)

- Author: Raphael Goncalves (Rgsdev), @rgs_dev
- Fetched from: https://opengameart.org/content/free-low-poly-vehicles-pack (file: https://opengameart.org/sites/default/files/free_low_poly_vehicles_pack_by_rgsdev.zip), with plain curl and a descriptive user agent
- Licence: CC0 1.0 (the author's own License.txt is next to this file: "public domain and free to use on any project, even commercial, credit is not required"; credited anyway)
- Kept here: the licence only. The FBX files (about 1 MB) are not committed; the 13 vehicles the game uses are converted and size-reduced in godot/assets/models/rv_*.glb (about 1.2 MB in all, plus rv_near.glb, the decimated sedan of the near traffic).
- Used by: godot/tools/open_models/convert_rgs_vehicles.py -> godot/assets/models/rv_<id>.glb (sedan, sport, compact = Hatchback, suv, taxi, van, luxury = Limousine, racer = Roadster, police = Police Sedan, ambulance, bus, muscle, pickup); VehicleSpecs key `rv`

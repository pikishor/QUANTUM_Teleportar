Every building is 28 m, so that is 6 floors plus the roof. - Floor slabs sit on the facade's own floor lines, and the window openings follow the facade's window grid. - Rooms and furniture differ by kind and are built only for the hero's floor and the ones next to it. - A roof door opens onto the same roof (lot.h) that zip and swing reach. - It costs one draw call, and only while a building is open. Small hooks in shared files: main.gd adds the module; city.gd is_inside_building() returns false for the open building; atmosphere.gd turns off the rain particles inside it.

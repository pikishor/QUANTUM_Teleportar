# Audio sources (open-source recordings)

Round 4: the weapon, impact, explosion, footstep, vehicle, UI and ambience sounds that used to be synthesised (and sounded like Tetris) are built from real CC0 recordings. Every pack was fetched from OpenGameArt.org with a plain, descriptive user agent; each page was checked to show the licence CC0 before the pack was used. Nothing else is used: no CC-BY, no NC, no sampling from games or sample libraries.

Pipeline: `tools/audio/real_clips.py` cuts the clips (kept in `art_sources/audio_<group>/clips/` with the pack's licence text in `LICENSE.txt` and a `SOURCE.md`) -> `tools/audio/make_real.py` builds `godot/assets/audio/*` (real transient + our own sub-bass / tail where useful, mastered to the peak and K-weighted loudness of the sound it replaces; `tools/audio/real_levels.py` holds the numbers of the synthesised originals, so the mix table of `Sfx` and `tools/audio/check_audio.py` stays as tuned) -> `tools/audio/shrink_audio.py`. `tools/build_assets.sh` runs it after all synthesising generators. `tools/audio/write_audio_sources.py` regenerates the provenance files and this table.

## What is real now

| Sound family | Made from |
|---|---|
| Rifle shots `shot`, `shot_1..3` | AR-15, AK-47, SKS and Savage .300 recordings (Free Firearm Sound Library), sub-bass thump and a crack boost on top |
| Pistols `shot_twin`, `_1`, `_2` | 1911, Walther PPQ, Bersa |
| Revolvers `shot_rev`, `_1`, `_2` | Smith & Wesson 642, Ruger Single Six, Marlin 336, pitched down with a heavy sub |
| Shotguns `shot_scatter`, `_1`, `_2` | Mossberg, Nova, Model 12 |
| Minigun `shot_mini`, `_1..3` and burst `shot_burst`, `_1..3` | single rounds cut from PPSh-41 and Carl Gustav M45 bursts (four different rounds, so a long burst does not machine-gun one sample) |
| Pulse classes `shot_flux`, `shot_arc`, `shot_rail`, `shot_lance`, `shot_gravity` | Kenney laser / force-field samples over real firearm transients and our own sub-bass |
| Suppressed `shot_supp_*` | the 'Hollywood silencer' recording |
| Overcharged `shot_oc_*` | real laser + black-powder boom + rocket over the synthesised sub fall and shimmer |
| Distant `shot_far_*`, `enemy_shot_far_*`, `distant_gunfire_*`, `distant_boom_*` | the library's mid-distance recordings and real far explosions, low-passed |
| Enemy fire `enemy_shot*` | SMG / pistol / rifle transients with a Kenney zap, pitched down so it reads as theirs |
| Reloads, dry fire, ricochets, whizz, melee | Joaken / starninjas / Brian MacIntosh reloads, equipment clicks, metal clinks with a falling pitch, qubodup swishes |
| Impacts `impact_*`, landings, hit markers | qubodup meat / stone / metal impacts and punches, 75 CC0 breaking sounds, glass and metal hits |
| Explosions `boom*`, `explosion_small_*` | real booms (Chunky, number99, Kenney, cannon / firework bangs) over a synthesised sub-bass fall |
| Car crashes and bumps | real metal / glass / rock breaking with a thump and a street tail |
| Footsteps (asphalt, metal, stairs, tile, carpet, roof) | Fantozzi stone and sand, metal-on-concrete, subway, wood and gravel steps |
| Engines `engine_*` | qubodup racing-car loops (whole cycles, seamless); bike and heavy variants re-pitched circularly |
| Engine start, horn, car door | car engine start recordings, car sound effects pack, MedicineStorm's car door |
| UI cues `ui_*` | Kenney Interface Sounds, gopherapps UI SFX, number99 terminal beeps |
| Beds `rain_*`, `traffic_far`, `wind`, `city_hum` | Snabisch rain and traffic, a windy ambience, the 2DPIXX sci-fi city loop, crossfaded to 24 s seamless loops |

Still synthesised (no suitable CC0 source found or fetched): tyre squeal (`tyre_squeal`), `engine_hover_*`, the quantum ability sounds (blink, link, superposition, collapse: these are the game's own identity), voices (troopers, aliens, hero, radio babble), music and stings, heartbeat and breath, sirens, pickups.

Blocked or unusable: kenney.nl returns 403 to scripts, so Kenney's packs came through their CC0 re-uploads on OpenGameArt (their License.txt is kept); the 'SuperTuxKart sound effects' pack (OpenGameArt) is one 82 s unlabelled mp3 with no way to tell skids from crashes, so it was not used; 'Footsteps Leather, Cloth, Armor' is dual-licensed OGA-BY / CC0 and was skipped to keep the list strictly CC0.

Size: art_sources clips 3.6 MB (kept in the repo so the build is reproducible); assets/audio stays inside the 24 MB budget of test_audio_budget2.
